## 🚀 Getting Started

### Prerequisites

Make sure you have **Node.js** installed.

### Installation

Clone the repository:

```bash
git clone https://github.com/erdonakadriolli/ErdonaKadriolliPortfolio.git
```

Go to the project directory:

```bash
cd ErdonaKadriolliPortfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## 📦 Production Build

Create a production build:

```bash
npm run build
```

Start the production server:

```bash
npm start
```
